# Chinnarasu A — Developer Portfolio

Modern responsive portfolio built with HTML, CSS and JavaScript.

## Sections
- Introduction and resume download
- About, technical skills, internship experience and education
- Personal projects with GitHub source links
- Internship project summaries, marked separately from public repositories
- Contact links for email, GitHub and LinkedIn

## Run locally
Open `index.html` in a browser. No build tools are required.

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. After publication, visit `https://g534767.github.io/chinnarasu-portfolio/`.

## Notes
The resume PDF is stored in `assets/`. Check personal details and internship dates before sharing publicly.
